--------------------------------------------------------------------------
                            Release Notes for
                            QUD Userspace Linux Installer 1.00.1.9
                            9/16/2026
--------------------------------------------------------------------------

---------------------
Component Description
---------------------

Qualcomm USB host drivers (user pace) providing logical representations of
Qualcomm® chipset-enabled mobile devices over USB connection.

--------
Contacts
--------

<host-drivers.team>: For any question or comment regarding QUD userspace driver.

-------------------------------------------------------------
New Features and CR Summary 1.00.1.9
-------------------------------------------------------------
1. Final release of userspace Linux installer. Future releases of
   our dependent tool will ship an independent of driver installer.
2. Added support to detect and remove existing QUD installations
   performed via qsc-cli.
3. Minor fix to remove residual scripts from install directory.
-------------------------------------------------------------

-------------------------------------------------------------
New Features and CR Summary 1.00.1.8
-------------------------------------------------------------
1. Fix dpkg installing twice. moved removal of qud kernel driver
section in preinst, before payload unpack. preventing dpkg's
`Conflicts/Replaces` from triggering a second removal after files
are installed.
-------------------------------------------------------------

-------------------------------------------------------------
New Features and CR Summary 1.00.1.7
-------------------------------------------------------------
1. The libusb package is installed by the installer at a
   system-defined location. DLLs are not bundled with the installer.
2. Handles removal of the legacy kernel driver and its dependencies,
   replacing them with the latest userspace installer.
3. Adds support to detect and remove existing QUD installations
   performed via qpm-cli.
4. Updated driver script.
-------------------------------------------------------------

-------------------------------------------------------------
New Features and CR Summary 1.00.1.6
-------------------------------------------------------------
1. Installation/Uninstallation output will be saved under
   /opt/qcom/QUD_Userspace/qcom_userspace_install.log
2. Updated Userspace installer background in ReadME
3. Adding functionality to remove open-source qmi_wwan driver
4. Updated qcom_driver.sh and QcDevDriver.sh
-------------------------------------------------------------

-------------------------------------------------------------
New Features and CR Summary 1.00.1.5
-------------------------------------------------------------
1. Added fixes to address LIBUSB_ERROR_ACCESS by configuring
appropriate udev rules to grant device access to non-root users.
-------------------------------------------------------------

-------------------------------------------------------------
New Features and CR Summary 1.00.1.4

independent of Qualcomm proprietary QIK installer.
-------------------------------------------------------------
